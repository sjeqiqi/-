# 奶山羊日粮配比助手 - 微信小程序原生前端

## 概述

本项目为“奶山羊日粮精准配比助手”微信小程序原生工程，基于微信云托管服务 `django-olww`（FastAPI 后端）进行数据通信与日粮配比优化计算。

---

## 核心特性

1. **三步向导流程**：
   - **Step 1 羊只信息录入**：支持泌乳期与维持期羊只，体重（25-90 kg）、日产奶量（0.2-5.0 kg/d）、乳脂率（2.0-7.0%）智能校验。
   - **Step 2 原料与价格选择**：精料、粗料、矿物质分类呈现；支持“推荐模式”与“自选模式”；支持展开录入原料营养实测值；提供粗料缺失、食盐缺失等智能预警。
   - **Step 3 配方结果与营养复核**：展示 10g 精度的每日投喂克数、干物质、日成本；逐项核对《奶山羊饲养管理技术规范》（NY/T 2835-2015）及《肉羊营养需要量》（NY/T 816-2021）；提供贴边黄色余量提醒、近似配比标红警示以及四大科学解读维度。
2. **微信原生云托管直连 (`wx.cloud.callContainer`)**：
   - 走微信专线直连云托管服务 `django-olww`，**无需配置任何 request 合法域名，无需工信部 ICP 域名备案**。
   - 内置智能降级机制，支持开发工具本地 HTTP 测试。
3. **AI 智能通俗解读**：
   - 针对合格配方支持一键生成 AI 通俗解读；无 API 密钥时自动采用本地安全回退说明。

2. 点击 **导入项目**。
3. 项目目录选择：
   ```text

   ```
4. AppID 选择您的小程序 AppID（或选择测试号）。
5. 点击导入并编译，即可直接在开发者工具中运行体验！
